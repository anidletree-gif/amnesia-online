# 🧠 失忆症 Online · 记忆裂痕

> **失忆症 —— 一款推理不对称桌游（1.0 beta）**

你醒来时，什么都不记得了。
只记得：**凶手，就在你们中间。**

失忆症 Online 是一款 6~8 人联机身份推理桌游：好人阵营在失忆中寻找真凶，凶手阵营在暗中编织谎言，中立阵营则伺机独活到最后。谁能在记忆碎片中拼出真相，谁就能活过今晚。

---

## 🎲 玩法亮点

- **不对称阵营对抗**：3 大阵营、8 种身份，每种角色都有独特的夜间能力与"翻牌"后果，一局游戏多种策略深度。
- **翻牌博弈，一步天堂一步地狱**：夜晚行动时你可以在目标身上**翻一张牌**——翻对了真相大白，翻错了……你可能会当场死亡。运气与推理同样重要。
- **夜间暗杀 × 白天辩论 × 投票处决**：完整的"夜晚行动 → 白天发言 → 投票处决"循环，节奏紧凑不拖沓。
- **实时语音开黑**：支持 WebRTC 语音，白天仅当前发言人可发声，辩论更有仪式感。
- **断线重连，对局不中断**：网络波动也能恢复对局，房主掉线有宽限保护。
- **多端支持**：网页端即开即玩，另有 Android 原生客户端（5.0-native）。

## 🃏 角色阵营（8 种身份）

| 阵营 | 角色 | 夜间能力 | 翻牌后果 |
|------|------|----------|----------|
| 🔪 凶手阵营 | **凶手** | 每晚必杀一人 | 翻到与自己相同牌 → 暴露 |
| 🔪 凶手阵营 | **虚构者** | 条件苏醒，可对目标施放"查验反转"标记，扰乱侦探情报 | 特殊翻牌机制 |
| 🛡️ 好人阵营 | **侦探** | 查验结果**绝对真实** | 翻到与自己相同牌 → 暴露 |
| 🛡️ 好人阵营 | **错构者** | 查验结果与上一轮行动相关，需自行解读 | 翻到与自己相同牌 → 暴露 |
| 🛡️ 好人阵营 | **精神分裂** | 查验结果固定为"是凶手"，真假难辨 | 翻牌必死 |
| 🛡️ 好人阵营 | **失忆者** | 查验结果固定为"非凶手" | **翻牌必死**（最容易误伤的"平民"） |
| ⚖️ 中立阵营 | **精神病** | — | **翻牌永不死亡**，但也不被信任 |
| ⚖️ 中立阵营 | **人格分裂** | 每晚随机复制一名存活玩家的角色能力（暗杀/查验），目标每夜随机切换 | 翻到与自己相同牌 → 暴露 |

**胜负条件**：凶手屠戮好人 / 好人阵营找出并处决全部凶手 / 中立阵营独活 2 人即胜。

## 🎮 对局流程

1. **建房**：房主选择板子（6 人基础 / 8 人进阶），好友加入房间。
2. **夜晚**（30s）：每人秘密行动——`暗杀` / `查验`，可选 `翻牌` 追加风险博弈；行动超时由系统代打。
3. **白天**（发言限时 60s）：公布死者名单，仅当前发言人可发言（语音 / 文字），限时轮转。
4. **投票**（30s）：全员票选处决对象，可弃权，平票不处决。
5. **结算**：达成任一阵营胜利条件即结束，房主可一键重置再开。

> 板子配置：
> - **6 人基础**：凶手 ×1 + 侦探 ×1 + 精神病 ×1 + 失忆者 ×3
> - **8 人进阶**：凶手 ×1 + 虚构者 ×1 + 侦探 ×1 + 错构者 ×1 + 精神分裂 ×1 + 精神病 ×1 + 失忆者 ×2

## 🚀 快速开始

### 服务端（Node.js ≥ 18）

```bash
cd server
npm install        # 安装依赖（ws / bcryptjs / multer / nodemailer）
npm start          # 或 bash start.sh（含自检与健康检查）
```

启动后：

- 网页端：`http://<服务器IP>:3000`
- 默认端口：`3000`（可用环境变量 `PORT` 覆盖）

> 默认 `OPEN_REGISTER: true` 开放注册，局域网开服免邮箱验证码，任意邮箱格式即可注册。

### 部署配置（`server/config.js`）

| 配置 | 默认 | 说明 |
|------|------|------|
| `PORT` | 3000 | 监听端口 |
| `ALLOWED_HOST` | null | 公网域名白名单，null 不限制 |
| `OPEN_REGISTER` | true | 开放注册（免邮箱验证） |
| `ACTION_TIMEOUT` | 30000 | 夜晚行动超时（ms） |
| `SPEAK_TIMEOUT` | 60000 | 白天单人次发言超时（ms） |
| `VOTE_TIMEOUT` | 30000 | 投票超时（ms） |
| `SMTP_USER/PASS` | 占位符 | 需要邮件验证时替换为自己的 SMTP 授权码 |

### Android 客户端

```bash
cd android
./gradlew assembleDebug     # 生成 debug APK
```

## ❓ FAQ

- **为什么我翻牌死掉了？** 失忆者翻牌必死、精神分裂翻牌必死——翻牌是高风险高收益的博弈，量力而行 😉
- **白天可以随便说话吗？** 不可以，只有当前发言人能发声（文字/语音），限时 60s，更有辩论节奏。
- **平票会怎样？** 平票不处决任何人，直接进入下一天。
- **断线了怎么办？** 对局会保留你的状态，重连即可恢复；房主断线有 30s 宽限。
